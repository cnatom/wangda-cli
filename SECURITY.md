# Security and responsible use

This project is unofficial and is not affiliated with China Mobile. Only use accounts and courses you are authorized to access, within applicable platform and employer rules. It performs real playback and ordinary UI interaction; it does not establish comprehension, attendance, or fulfillment of mandatory personal-study requirements.

No fabricated learning time/completion reports, direct reporting API shortcuts, examination automation, or server-concurrency bypasses are supported.

Browser profile data includes credentials. Keep it local, private, and out of sync/shared folders and source control. Never point `--profile` at your everyday browser's data directory. CDP gives full control of the dedicated browser: keep it on loopback, do not expose the port or mount it into an untrusted environment, and do not share the account with other local users.

Snapshots/logs are local and may still contain course identifiers/progress. Sanitization is not a guarantee that arbitrary text is safe to publish. Downloaded certificates contain the learner's name and certificate number; keep them local and never upload or paste them. Runtime files are excluded from Git. Do not attach profiles, raw screenshots, HARs, network logs, cookies, phone/SMS codes, passwords, or tokens to public issues.

For security concerns, contact the maintainer privately through their GitHub profile rather than posting exploit details or secrets in a public issue. Use synthetic reproductions in ordinary bug reports.
